# Ozon Job Календарь

Календарь рабочих смен сотрудников Ozon с выбором склада.

## Разработка

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run lint
npm run build
```

## Публикация

```bash
npm run deploy
```

Приложение публикуется в GitHub Pages по пути `/ozon-job-calendar`.

Для публикации зеркала в корне домена соберите проект так:

```bash
VITE_BASE_PATH=/ npm run build
```

Содержимое `dist` можно разместить на любом статическом HTTPS-хостинге. После
первого успешного открытия приложение сохраняет оболочку локально и может
запускаться без сети. Фотографии сотрудников офлайн не гарантируются, так как
загружаются с внешнего домена.
